# HTTP MJPEG 浏览器预览设计

已确认：保留板上 LCD 的 800×480 RGB565 实时显示，增加浏览器预览。

- CM7 继续在 TCP 80 提供 HTTP。`GET /` 返回包含 `<img src="/stream">` 的页面；`GET /stream` 转交独立任务，保持连接并发送 `multipart/x-mixed-replace; boundary=frame`。每部分包含 JPEG 类型、长度和完整 JPEG，正常播放不主动断开。
- 保留现有相机三缓冲。复制显示帧期间暂缓软件换帧，DMA 继续采集到其他缓冲；CPU 读取前失效缓存。编码和网络发送使用独立 SDRAM，不占用采集帧。
- RGB565 经 ST jpeg_utils 转换为 YCbCr 4:2:0 MCU，再经 JPEG/MDMA 编码；质量 60，发送节流上限 10 FPS，不承诺未经实测的帧率。无观看者时不编码。
- 单个观看连接；额外连接返回 503。HTTP 主任务继续服务状态和 OTA。发送超时、编码错误或断线回收连接，刷新页面可重连。
- OTA 擦写前停止推流并等待编码/快照退出，然后执行现有相机暂停流程。OTA 优先，期间拒绝新推流，结束后用户刷新恢复。
- 验证 CM7 A/B 构建；设备验证需确认 multipart、多帧 JPEG 解码、断线重连、并发状态请求和 LCD 实际画面。构建通过不代表硬件验证完成。
