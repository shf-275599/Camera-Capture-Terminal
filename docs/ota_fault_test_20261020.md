# OTA 失败回滚与物理断电实测记录

测试日期：2026-10-20。设备 IP：192.168.10.2。串口：COM8，115200 8-N-1。
ST-Link SN：38FF72064B58333828282443。

## 失败回滚

初始两核均运行并确认 A，无 pending。使用现有 B BIN 的副本，在反汇编确认的看门狗初始化返回点，将后续四字节替换为 `72 B6 FE E7`（关中断、原地循环）。通过正常 HTTP OTA 上传，CRC 按修改后的镜像重新计算；此阶段未修改工程源码或正常 BIN。

| 目标核 | 镜像长度 | 修改位置（BIN 偏移） | 失败镜像 CRC32 | 结果 |
| --- | ---: | --- | --- | --- |
| CM7 | 151940 | 0x6002 | 0x9A4A8D41 | 三次进入 B，trial 3→2→1→0，随后自动回 A，pending 清除 |
| CM4 | 23276 | 0x05FA | 0xC6F15777 | 三次选择 B 并发生自动复位，trial 3→2→1→0，随后选择 A，pending 清除 |

两次均捕获 COM8 启动日志，并查询确认两核 running=0、active=0、flags=0x00、trial=0、busy=0。
CM7 测试前第一次 begin 返回 HTTP 503 / rc=-9，串口为 CAMERA_THREAD_FAIL；擦除未开始。经 ST-Link 复位后重试成功。该摄像头暂停失败现象未在本轮修复。

## 物理断电

由用户手动切断全部供电，确认屏幕与电源指示灯熄灭，保持至少 5 秒后上电。

| 场景 | 准备状态 | 结果 |
| --- | --- | --- |
| CM7 写入未完成 | 擦除 B，写入前 8192 字节，不发送 end | 用户确认冷启动画面正常；HTTP 确认两核仍运行 A，无 pending、无残留会话 |
| CM4 写入未完成 | 擦除 B，写入前 8192 字节，不发送 end | 用户确认冷启动画面正常；HTTP 确认两核仍运行 A，无 pending、无残留会话 |
| 成功升级后的冷启动 | 两核重新上传正常 B 镜像并复位 | 用户确认冷启动画面正常；HTTP 确认两核 running=1、active=1、flags=0x00、trial=0、busy=0 |

写入未完成测试的断电发生在块间暂停期间，不能视为命中 Flash 编程脉冲或擦除正在进行的瞬间。

## 扩展断电测试

用户授权加入临时测试模式后，在 CM7 A 候选提交前循环调用原有 EEPROM 保存接口，每轮最多 512 次，然后停止喂狗。confirmed 保持正常 B，候选不提交。Windows 构建命令：

```powershell
make -s -C Makefile/CM7 APP_SLOT=A BUILD_DIR=build_power TARGET=BaseProject_CM7_power "OPT=-Og -DOTA_EEPROM_POWER_TEST" -j8
```

构建通过（保留原有 RWX LOAD 警告）。测试 BIN 长度 152192，CRC32 0xA5AA3D66，版本 9200。串口捕获 POWER-TEST START 和 WRITING 后，用户确认物理断电并重新上电。候选后续未确认，trial 耗尽后恢复正常 B；捕获到有效 EEPROM 记录 seq=1535，回退后 seq=1536，HTTP 和相机帧检查恢复。

本轮未捕获刚上电时的双备份有效性，不证明命中单次 EEPROM 写周期或产生过损坏副本；验证范围为重复保存 pending 记录期间的物理断电恢复。

另执行空闲 CM7 B 的重复擦除/abort。第一轮用户反馈未赶上；第二轮用户确认断电过，但串口记录未提供明确的擦除忙期间掉电证据，因此不计为擦除瞬间命中。用户期间反馈帧率低；停止重复擦除、恢复正常镜像并复位后，用户确认画面帧率恢复正常。

临时源码测试段已撤除，build_power 已删除，CM7 A 已通过正常 OTA 覆盖为正常镜像（版本 9201）。
