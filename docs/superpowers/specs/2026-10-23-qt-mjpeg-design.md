# Qt 摄像头实时预览接入设计

用户已确认 Qt 适配当前固件的 HTTP MJPEG 接口。

- 固件维持 TCP 80 的 `GET /stream`，Qt 默认端口改为 80。连接后发送 HTTP GET，验证 200 响应与 multipart 类型，从响应获取 boundary，按各部分的 Content-Length 接收 JPEG。
- 保留工作线程内的网络接收和 JPEG 解码、界面定时获取最新图像、800×480 尺寸校验、等比例显示、完整帧接收速率与解码计数。HTTP/部分头最大 8 KiB，JPEG 最大 512 KiB，避免异常响应无限积累。
- HTTP 503 显示设备忙碌或 OTA 中，其他 HTTP/协议错误显示具体状态；网络断开或五秒无数据后每秒尝试重连。主动断开、关闭窗口停止工作线程。每次连接独立解析，不沿用半帧。
- 修改 Qt 模拟测试，覆盖 GET 请求、分包、粘包、不同 boundary、超限长度、半帧断线、重连和 503。Windows PowerShell 执行现有 build.ps1 构建部署，运行协议测试与 GUI 启动测试。
- 实机验收需运行当前 HTTP MJPEG 固件的设备在线，并填写可达 IP。浏览器与 Qt 共用单观看者限制，验收时关闭其他视频观看连接。构建、模拟通过不代表实机图像和帧率已验证。
